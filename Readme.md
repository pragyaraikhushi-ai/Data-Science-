<p>This is a Data Science project that focuses on analyzing traffic accident data across different states, union territories, and cities in India. The dataset includes information on road accidents, railway accidents, railway crossing accidents, and total traffic accidents, along with their distribution across months.</p>
<br>
<p>The primary objective of the project is to identify patterns, trends, and key risk factors contributing to accidents using data analysis and visualization techniques.</p>
